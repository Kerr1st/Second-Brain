# Effectiveness evaluation: acceptance criteria

Reviewed against refactor source on 2026-09-26. These requirements describe behavior, not deployed status.

1. Freeze 1–35 records with source identities, content hashes, a current task and explicit omitted stages.
2. Bind execution to the reviewed manifest, role/skim configuration and embedding destination; reject drift before ingestion.
3. Verify the actual connection uses the new socket-only cluster and all application tables start empty.
4. Capture ordinary retrieval before native discovery; retain stage status, candidate evidence, briefing and blinded packets.
5. Report aborts, known reasoning cost, missing spend and unmeasured embedding cost without fabricated completion or zero charges.
6. Accept explicit human ratings with supporting observations; leave usefulness, action and outcome unknown until reviewed.

Qualification evidence and unresolved release gates belong in the [completion ledger](../../../docs/REFACTOR-COMPLETION-2026-09-26.md).
