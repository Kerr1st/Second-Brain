# Historical design and operation records

These files were retained verbatim from the pre-refactor committed tree (`1071a81`, the installed `main` until 2026-10-05) when the September 26 documentation layout was adopted. They are evidence of earlier designs and observations, not current operating instructions; several describe the knowledge-graph tables, the JSON backup exports, Docker, the Kiro `laptop` profile and the staged chat pipeline, all of which the release line has since removed or replaced. Follow [the current entrypoint](../../START-HERE.md). Relative links inside these historical files reflect their original locations; code comments that cite `docs/PLAN-*.md`, `docs/RESEARCH-skim-model.md`, `docs/FABLE5-THINKER-PLAN.md` or `docs/DREAM-CYCLE-MCP-DECOUPLING.md` resolve to this directory.

`specs/` holds the twelve original `.kiro/specs` families as committed; nine are superseded by the active families listed in [SPEC-INDEX.md](../../SPEC-INDEX.md), three (`db-layer-hardening`, `evaluation-framework`, `project-auto-tagging`) were rewritten in place and keep their name. The installed working tree's 2026-09-10 versions of the documentation (redirect stubs plus the new orientation files) are in [../2026-09-10-installed/](../2026-09-10-installed/README.md); the user's own generalized snapshot of the pre-stub originals is in [../2026-09-10/](../2026-09-10/README-ARCHIVE.md).
