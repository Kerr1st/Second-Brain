# Second Brain User Guide

Second Brain is a self-hosted persistent-memory and autonomous-synthesis layer for AI agents. It captures knowledge from your conversations, documents, and feeds, then retrieves it by meaning and autonomously surfaces connections and insights — so your AI agents remember across sessions and think with you over time.

## Who this guide is for

You run your own infrastructure and are comfortable with a terminal, PostgreSQL, and Python. You want to understand, install, operate, or extend Second Brain.

## Start here

1. Read the [Overview](overview.md) to understand how the system works.
2. Follow [Getting started](getting-started.md) to install and verify.
3. Use [Using Second Brain](using-second-brain.md) for day-to-day workflows.
